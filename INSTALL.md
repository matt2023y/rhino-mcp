# 安装说明 / Installation

## 中文

1. 下载对应的 ZIP：
   - Codex 和犀牛在同一台电脑：Windows 下载 [windows.zip](dist/windows/rhino-mcp-modeling-windows-amd64.zip)，Mac 下载 [mac.zip](dist/macos/rhino-mcp-modeling-macos-universal.zip)。
   - 不同电脑：按运行 Codex 的电脑系统选择 ZIP。
2. 把下载的 ZIP 文件交给 Codex，输入：**安装 skill**。
3. 安装完成后，输入：**配置 犀牛 MCP**。
4. 按照提示输入信息，完成配置即可。

## English

1. Download the ZIP for your system:
   - Codex and Rhino on the same computer: download [windows.zip](dist/windows/rhino-mcp-modeling-windows-amd64.zip) for Windows or [mac.zip](dist/macos/rhino-mcp-modeling-macos-universal.zip) for Mac.
   - Separate computers: choose the ZIP for the computer running Codex.
2. Give the downloaded ZIP file to Codex and enter: **Install the skill**.
3. Once installed, enter: **Configure Rhino MCP**.
4. Follow the prompts and provide the requested information to finish setup.
